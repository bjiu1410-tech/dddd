# ⚡ 호그와트 마법 결투

주문을 **소리 내어 외치고**, 폰을 **지팡이처럼 휘둘러** 마법을 쏘는 해리포터 결투 웹 게임입니다.
설치할 것 없이 폰 브라우저에서 바로 실행됩니다.

## 플레이 방법

1. 상대를 고르고 **결투 시작** → 마이크·모션 센서 권한을 허용합니다.
2. 주문을 외칩니다. 예: "스투페파이!"
3. 화면에 **"휘둘러라!"**가 뜨면 4초 안에 폰을 휘두릅니다.
   - 센 주문일수록 **더 세게**, 주문마다 정해진 만큼 **더 오래** 휘둘러야 합니다.
   - 세기와 길이 막대가 흰 선(요구치)을 넘기면 초록색이 됩니다. 손을 멈추면 발사됩니다.
   - 요구치의 60%가 안 되면 실패하고, 넘치게 휘두르면 위력이 최대 1.5배가 됩니다.
4. 적이 주문을 외우는 동안(빨간 막대) **엑스펠리아르무스**나 **스투페파이**를 맞히면 시전이 끊깁니다.
   **프로테고**로 막을 수 있지만 **아바다 케다브라**는 막을 수 없으니 끊어야 합니다.

| 주문 | 효과 | 세기 | 휘두르는 시간 | 마나 |
|---|---|---|---|---|
| 프로테고 | 방패 | ★ | 0.15초 | 10 |
| 엑스펠리아르무스 | 무장해제 · 시전 끊기 | ★★ | 0.3초 | 12 |
| 스투페파이 | 기절 · 시전 끊기 | ★★ | 0.45초 | 18 |
| 에피스키 | 회복 (약하게, 오래) | ★ | 0.9초 | 22 |
| 인센디오 | 공격 18 | ★★★ | 0.6초 | 16 |
| 컨프링고 | 공격 25 | ★★★ | 0.8초 | 24 |
| 섹튬셈프라 | 공격 33 | ★★★★ | 1.1초 | 32 |
| 아바다 케다브라 | 공격 60 · 방어 불가 | ★★★★★ | 1.8초 | 60 |

상대: 연습용 허수아비(공격 안 함) → 드레이코 말포이 → 벨라트릭스 → 볼드모트

**휘두르기가 너무 어렵거나 쉬우면** 메뉴의 *휘두르기 감도*를 조절하세요. 메뉴 화면에서 폰을 흔들면 현재 세기가 표시됩니다.

센서나 마이크가 없을 때(PC 등):
- 전투 화면을 마우스/손가락으로 빠르게 문지르면 휘두르기로 인식합니다.
- 📖 주문서에서 주문을 눌러 시전할 수 있습니다.

## 실행

마이크와 모션 센서는 **HTTPS**(또는 localhost)에서만 동작합니다.

- **GitHub Pages**: `.github/workflows/pages.yml` 이 푸시할 때마다 테스트 후 자동 배포합니다.
  처음 한 번만 저장소 Settings → Pages → *Build and deployment* → Source 를 **GitHub Actions** 로 바꿔 주세요.
  (이 저장소는 공개라 무료로 쓸 수 있습니다.)
  주소: `https://bjiu1410-tech.github.io/dddd/`
- **로컬**: `npm start` (= `python3 -m http.server 8080`) 후 PC에서 `http://localhost:8080`.
  폰에서 테스트하려면 HTTPS 터널(예: `npx localtunnel --port 8080`)을 쓰세요.

권장 브라우저: 안드로이드 Chrome, iOS Safari (iOS는 설정에서 Siri가 켜져 있어야 음성 인식이 됩니다).

## 구조

```
index.html        화면 (메뉴 / 전투 / 주문서 / 결과)
style.css
js/spells.js      주문·적 데이터 (위력, 필요 세기/시간, 인식용 표기)
js/matcher.js     음성 인식 결과 → 주문 매칭 (한글 자모 단위 편집 거리로 받아쓰기 오차 허용)
js/swing.js       가속도·회전 센서 → 휘두르기 세기/시간 측정, 판정
js/game.js        게임 루프, 적 AI, 음성 인식, 화면 갱신
js/effects.js     캔버스 마법 광선·파티클
js/audio.js       Web Audio 합성 효과음, 진동
test/             매칭·휘두르기 판정 단위 테스트 (npm test)
```

새 주문은 `js/spells.js`의 `SPELLS`에 추가하면 됩니다 (`force`: 필요한 세기 m/s², `duration`: 필요한 휘두르기 시간 ms).
